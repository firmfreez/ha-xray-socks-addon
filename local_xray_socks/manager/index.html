VPN Manager

VLESS, AmneziaWG, OpenVPN и Check Point. Каждое подключение использует свой порт SOCKS5 с TCP и UDP.

Новое подключение

TCP и UDP доступны на выбранном порту SOCKS5.
Нужны для имён внутренних сайтов. Без DNS можно проверять доступ по IP. DNS самого VPN-сервера обрабатывается отдельно.
Пустые поля паролей при редактировании сохраняют прежние значения. Файлы с тем же именем заменяются. Секреты хранятся в данных аддона и попадают в его резервную копию.
