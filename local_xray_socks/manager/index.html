Новое подключение

TCP и UDP доступны на выбранном порту SOCKS5.
Выберите ваш файл .p12. Он должен содержать личный сертификат и закрытый ключ. Отдельный .cer не подходит. Для Personal Certificate логин и пароль учётной записи не нужны.
Аддон выберет метод автоматически, если сервер предлагает один подходящий вариант. Личный сертификат и пароль при запросе списка не отправляются.
Дополнительные настройки Check Point
Если UDP недоступен в вашей сети, попробуйте SSL. Это сертификат центра, которому доверяет VPN-сервер, а не ваш личный .p12. При необходимости загрузите его ниже в дополнительных файлах и сначала сохраните профиль.
После подключения подтвердите push на телефоне. Ожидание входа — до 3 минут. Сервер должен поддерживать вход через OpenConnect без браузера.
Дополнительные настройки AnyConnect / MFA
Пустое поле включает автоматический ответ для стандартных MFA-полей (secondary_password, password2 и challenge). При необходимости укажите точное поле, например main:secondary_password или challenge:password. Значение обычно push; уточните у администратора VPN. Повторный запрос основного пароля не заполняется автоматически.
OpenVPN, Check Point и AnyConnect получают DNS от VPN-сервера автоматически. Обычно оставьте поле пустым. Заполните его только для ручного выбора корпоративного DNS.
Повторы с задержкой от 5 секунд до 5 минут. Лимит считается до восстановления связи; ошибки авторизации останавливают повторы. AnyConnect может снова запросить push.
Выберите один или несколько телефонов из приложения Home Assistant. Одно уведомление на сбой; при ручном отключении уведомление не отправляется.
Пустые поля паролей при редактировании сохраняют прежние значения. Файлы с тем же именем заменяются. Секреты хранятся в данных аддона и попадают в его резервную копию.
